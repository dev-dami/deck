# Fonts

Geist Sans and Geist Mono, the variable woff2 files, copied from the
`geist` npm package, version 1.7.2 (`dist/fonts/geist-sans/Geist-Variable.woff2`
and `dist/fonts/geist-mono/GeistMono-Variable.woff2`). They are under the
SIL Open Font License 1.1, in `OFL.txt` (the package's `LICENSE.txt`).

`styles.css` loads them with `@font-face`; Vite copies them into the build.
